# AI Fraud Detection System

## Project Overview
The AI Fraud Detection System is a Machine Learning project designed to identify potentially fraudulent transactions and analyze suspicious transaction patterns.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- XGBoost
- MySQL
- Power BI

## Machine Learning Models
The following algorithms were implemented and evaluated:
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Model Building
6. Model Training and Prediction
7. Model Evaluation
8. SQL Analysis
9. Power BI Dashboard Development

## Model Evaluation
- **Best F1-Score:** XGBoost – 77.02%
- **Best Precision:** Random Forest – 96.40%
- **Best Accuracy:** Random Forest – 99.85%

## SQL Analysis
SQL queries were used to analyze:
- Total fraudulent transactions
- Highest fraud transaction amount
- Location-wise fraud analysis
- Customer transaction trends
- Merchant risk analysis

## Power BI Dashboard
The interactive dashboard includes:
- Total Transactions
- Fraud Transactions
- Safe Transactions
- Fraud Percentage
- Fraud Trend Analysis
- Location-wise Fraud Analysis
- Merchant Risk Analysis
- Transaction Category Analysis

## Note
The dataset is not included in this repository. The SQL analysis was performed on the successfully imported records, while the Power BI dashboard used the complete cleaned dataset.
